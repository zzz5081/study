## 一、命名规范

```
lc_编号_题目名.py        例：lc_0069_x的平方根.py
```

## 二、每题必须写这 3 行头注释

```python
# 题型: 二分查找 - 答案空间
# 关键点: 用 <= 让边界落在"第一个不满足条件"处 → 无条件 return left - 1
# 我踩的坑: 一开始写了 O(√x) 的线性循环，没答考点；判定条件用 < 导致 return 要分类讨论
```

### 第 3 行最重要 ⚠️

**"我踩的坑"是你自己的学习资产**，网上题解不会告诉你。

你的最大弱点是"记不牢"——而坑位记录就是治这个的。**两周后回来看这一行，比看十篇题解都有用。**

## 三、索引表（复习入口）

**考前 / 笔试前只看这张表。** 新做的题加一行。

| 编号 | 题目 | 题型 | 一句话关键点 |
|---|---|---|---|
| 704 | 二分查找 | 二分查找-基础 | `while left <= right` + `mid±1`；找到就 `return mid` |
| 35 | 搜索插入位置 | 二分查找-找边界 | **找不到时 `return left`（不是 `-1`）** |
| 34 | 查找第一个和最后一个位置 | 二分查找-找边界 | `lower_bound(t)` 与 `lower_bound(t+1)-1`；**必须 guard 越界**（`first == len`） |
| 278 | 第一个错误的版本 | 二分查找-找边界 | 相等时不停、往左压；题目保证有坏版本 → **不用 guard** |
| 69 | x 的平方根 | 二分查找-答案空间 | 用 `<=` 让边界落在"第一个不满足"处 → 无条件 `return left - 1` |
| 367 | 有效的完全平方数 | 二分查找-答案唯一 | 找到就 `return`（答案唯一，不需要压边界） |
| 875 | 爱吃香蕉的珂珂 | 二分查找-答案空间 | 判定函数 `sum(ceil(pile/k)) <= h`；`left` 不能从 0 开始（会除零） |
| 206 | 反转链表 | 链表-三指针 | 先存 next 再反转指向；**循环退出时 `prev` 才是新头** |
| 141 | 环形链表 | 链表-快慢指针 | `while fast and fast.next` —— **两个条件缺一不可**（快指针走两步） |

> ⚠️ 维护规则：写不出"一句话关键点" = 只是碰巧过了。
> 写的时候问自己：**只看这一行，两周后我能立刻想起怎么写吗？**
