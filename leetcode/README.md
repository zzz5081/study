## 五、公共工具：`leetcode/tree_utils.py`

**树题的工具函数抽出来了，不要每题重写一遍。**

```python
from tree_utils import TreeNode, build, to_list, preorder
```

| 函数 | 作用 |
|---|---|
| `TreeNode` | 节点类 |
| `build([4,2,7,1,3,6,9])` | LeetCode 层序数组 → 真正的树（`None` 表示空位） |
| **`to_list(node)`** | 树 → 层序数组（**用于 assert 比对**） |
| `preorder(node)` | 前序遍历（调试用） |

**为什么需要 `to_list`：**
> **`TreeNode` 没有定义 `__eq__`，所以 `TreeNode(1) == TreeNode(1)` 是 `False`**（比的是内存地址）。
> 要比"内容"必须拍平成可比的东西。

```python
# ❌ 永远为 False
assert s.invertTree(TreeNode(1)) == TreeNode(1)

# ✅ 比对值
assert to_list(s.invertTree(build([1]))) == [1]
```

**跑法**：`python leetcode\lc_0226_翻转二叉树.py`（`import` 用的是**脚本所在目录**，所以从哪跑都行）

> ⚠️ **写测试用 `is None` 而不是 `== None`**（`None` 是单例，身份比较更准确）
>
> ⚠️ **`build()` 的输入必须是合法的层序数组** —— 空位 `None` 也要占位。
> 例：`1 →右→ 2 →右→ 3` 是 `build([1, None, 2, None, 3])`，**不是** `[1,None,2,None,None,None,3]`（后面的 `3` 挂不上去）。
